# Bundled typefaces

- Cinzel, Copyright 2020 The Cinzel Project Authors. Original: https://github.com/google/fonts/tree/main/ofl/cinzel
- Barlow Semi Condensed Medium, Copyright 2017 The Barlow Project Authors. Original: https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed

The editable project archive includes the original font binaries and their respective SIL Open Font License 1.1 files, `OFL-Cinzel.txt` and `OFL-Barlow.txt`. For a source checkout, run `node scripts/fetch-native-fonts.mjs` from the repository root to fetch and verify the original font files.
